Sebelum mulai: apa itu program?

Cara pakai editor di halaman ini, dan cara membaca pesan galat.

Program adalah daftar perintah yang dijalankan komputer dari atas ke bawah. Mirip resep masakan, tapi pembacanya sangat patuh dan tidak bisa menebak maksudmu. Salah satu huruf saja, komputer berhenti dan memberi tahu letak kesalahannya.

Python adalah bahasa untuk menulis perintah itu. Dipakai di kuliah ini karena tulisannya mirip bahasa Inggris sederhana dan tidak banyak simbol.

P2

Variabel: menyimpan nilai

Memberi nama pada nilai, mengubah isinya, dan aturan penamaan.

Bayangkan variabel sebagai kotak berlabel. Kamu menaruh nilai di dalamnya, lalu memanggil isinya lewat label itu.

Membuat variabel

Tanda = di Python berarti isi kotak di kiri dengan nilai di kanan, bukan “sama dengan” seperti di matematika. Python selalu menghitung sisi kanan dulu, baru menyimpannya ke kiri.

Mengubah isi variabel

Isi variabel bisa berubah

Baris skor = skor + 5 terlihat aneh kalau dibaca sebagai persamaan. Baca begini: ambil isi skor (25), tambah 5, simpan hasilnya (30) kembali ke skor. Pola ini sangat sering dipakai untuk menghitung.

Python juga punya bentuk singkat: skor += 5 sama dengan skor = skor + 5. Ada juga -=, *=, dan /=.

Variabel menyimpan nilai, bukan rumus

Tebak dulu sebelum menjalankan

Hasilnya 10, bukan 200. Saat baris b = a * 2 dijalankan, a masih 5, jadi b diisi 10. Mengubah a sesudahnya tidak mengubah b.

Aturan nama

  • Boleh huruf, angka, dan underscore _. Tidak boleh spasi: pakai nilai_akhir, bukan nilai akhir.
  • Tidak boleh diawali angka: 2nilai salah.
  • Huruf besar dan kecil dibedakan: Nilai dan nilai dua kotak berbeda.
  • Tidak boleh memakai kata khusus Python seperti if, for, print sebaiknya juga jangan.
  • Pilih nama yang menjelaskan isi: harga_total lebih jelas daripada x.

Mengulang dengan while

Pengulangan selama kondisi benar, pencacah, sentinel, dan loop yang tidak berhenti.

while mengulang isi bloknya selama kondisi masih benar. Setiap putaran, Python memeriksa kondisi lagi.

Mengulang 5 kali

Urutannya: periksa i <= 5, jalankan isi, tambah i, kembali ke pemeriksaan. Saat i menjadi 6, kondisi salah dan loop berhenti.

Loop yang tidak pernah berhenti

Jika baris i = i + 1 dihapus, i selamanya 1 dan loop jalan terus. Di editor ini tekan Hentikan. Setiap menulis while, tanyakan: baris mana yang akan membuat kondisinya suatu saat salah?

Mengumpulkan hasil: akumulator

Menjumlahkan 1 sampai 10

Variabel total mulai dari 0 dan bertambah setiap putaran. Inisialisasi total = 0 harus di luar loop; kalau di dalam, nilainya terhapus tiap putaran.

Berhenti karena input: sentinel

while cocok ketika banyak ulangan belum diketahui. Contoh: baca angka terus sampai pengguna mengetik 0.

Baca sampai 0

Polanya: baca sekali sebelum loop, periksa, proses, lalu baca lagi di akhir isi loop. Angka 0 di sini disebut sentinel, penanda akhir data, dan tidak ikut dijumlahkan.

Dari soal ke kode

Langkah memecahkan soal yang belum pernah kamu lihat, plus dua proyek kecil.

Bagian tersulit coding bukan mengetik kode, melainkan tahu apa yang harus diketik. Pakai lima langkah ini untuk setiap soal. Langkah ini adalah empat pilar berpikir komputasional dalam praktik.

  1. Pahami. Apa inputnya? Apa outputnya? Tulis satu contoh input dan output yang benar.
  2. Kerjakan manual. Selesaikan contoh itu dengan tangan. Perhatikan apa yang kamu lakukan.
  3. Tulis langkahnya dalam bahasa Indonesia, baris demi baris.
  4. Terjemahkan setiap langkah menjadi kode.
  5. Uji dengan contoh, lalu kasus batas: nol, satu data, nilai tepat di batas.

Contoh: tarif parkir

Soal: tarif parkir Rp5.000 untuk 2 jam pertama, lalu Rp3.000 untuk setiap jam berikutnya. Baca lama parkir (jam, bilangan bulat ≥ 1), tampilkan tarifnya.

Pahami: input lama parkir, output tarif. Contoh: 5 jam → 5.000 + 3 × 3.000 = 14.000.

Langkah: baca jam. Jika jam ≤ 2, tarif 5.000. Selain itu, tarif = 5.000 + (jam − 2) × 3.000. Tampilkan tarif.

Terjemahan langsung dari langkah

Uji: 1 jam → 5.000, 2 jam → 5.000 (batas), 3 jam → 8.000, 5 jam → 14.000. Semua cocok dengan hitungan manual.

A.45.1 Duck typing

“Kalau berjalan seperti bebek dan bersuara seperti bebek, berarti bebek.” Python tidak peduli tipe object; yang penting object itu punya atribut atau method yang dipanggil. Jika ada, kode jalan. Jika tidak, muncul AttributeError saat dijalankan.

  • Atribut yang berisi closure (fungsi yang disimpan di atribut).
  • Atribut yang berisi lambda.
  • Class yang punya class method calculate_area; bahkan class-nya sendiri (bukan object) bisa dikirim ke do_the_math().

Penting

Python tetap bahasa dinamis. Tipe pada parameter hanya membuat editor atau type checker memberi warning; program tetap bisa dijalankan dan tidak error.

Percabangan

Bentuk if, analisis kasus, complete dan disjoint.

Tiga bentuk dasar

Pada rantai if-elif-else, Python memeriksa kondisi dari atas. Begitu satu kondisi benar, cabangnya dijalankan dan sisa rantai dilewati.

Analisis kasus: complete dan disjoint

Materi percabangan menekankan dua sifat yang harus kamu periksa setiap kali membuat cabang.

Complete

Seluruh kemungkinan dalam domain soal sudah ditangani. Klasifikasi bilangan di atas complete: setiap bilangan pasti positif, negatif, atau nol.

Disjoint

Kategori hasil tidak saling tumpang tindih. Setiap nilai masuk tepat satu kategori.

Contoh pembagian nilai yang complete dan disjoint:

x < 60   |   60 ≤ x < 80   |   x ≥ 80

Kondisi yang tertulis di kode berikut sebenarnya beririsan (nilai 90 memenuhi >= 80 dan >= 60). Urutan elif membuat hasilnya tetap disjoint, karena cabang kedua hanya diperiksa jika cabang pertama gagal.

Urutan yang salah

Kalau nilai >= 60 diletakkan di atas nilai >= 80, nilai 95 masuk kategori Sedang dan cabang Tinggi tidak pernah tercapai. Untuk kondisi “lebih dari atau sama dengan”, mulai dari batas terbesar.

Koreksi kecil pada slide

Bilangan positif memenuhi n > 0. Kondisi n ≥ 0 berarti nonnegatif, yang juga mencakup nol.

Kasus dengan kondisi gabungan: tahun kabisat

Tahun kabisat habis dibagi 4, kecuali tahun yang habis dibagi 100. Pengecualiannya punya pengecualian: tahun yang habis dibagi 400 tetap kabisat.

Uji dengan 2024 (kabisat), 1900 (bukan), 2000 (kabisat), dan 2023 (bukan). Memilih data uji yang menyentuh setiap cabang adalah cara cepat memeriksa sifat complete.

Percabangan bersarang

Jebakan percabangan
  • if x = 5: galat. Perbandingan memakai ==; tanda = hanya untuk mengisi variabel.
  • if x == "A" or "B": selalu benar, karena "B" sendiri dianggap benar. Tulis if x == "A" or x == "B":.
  • Lupa titik dua di akhir baris if, elif, atau else.

    Mengapa kondisi loop memakai and?

    Permainan berlanjut hanya selama kedua batas belum tercapai. Begitu salah satu tercapai, kondisi menjadi salah dan loop berhenti. Dengan or, loop baru berhenti setelah kedua batas tercapai.

    Cabang else terakhir aman tanpa memeriksa seri: lima ronde tidak seri dibagi ke dua pemain tidak mungkin sama banyak, karena 5 ganjil. Jika ronde kesepuluh tepat menjadi ronde tidak seri kelima, pemenang tetap bisa ditentukan.
